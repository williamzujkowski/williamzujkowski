## How It Works

The animated SVG terminal is generated by [svg-terminal](https://github.com/williamzujkowski/svg-terminal). All content and configuration lives in `terminal.yml` (desktop) and `terminal-mobile.yml` (mobile).

**To update the terminal content:** Edit `terminal.yml` or `terminal-mobile.yml` and push — `.github/workflows/update-terminal-svg.yml` regenerates all 4 SVGs via the published `williamzujkowski/svg-terminal@v1` GitHub Action (with `strict: 'true'`) and commits them. It also runs every 6h for daily theme rotation and live weather/stats data.

**To regenerate locally:**
```bash
# Using local svg-terminal or published CLI
npm run generate

# Or individually:
npm run generate:desktop
npm run generate:mobile
```

### What I'm focused on

- 🤖 **Multi-agent AI governance & orchestration** — [**nexus-agents**](https://github.com/nexus-substrate/nexus-agents) & [**kernloop**](https://github.com/williamzujkowski/kernloop): You can't prove the agent; prove the gate. Autonomic control plane with multi-model consensus voting (Claude, Gemini, Codex, OpenCode), hash-chained immutable audit trails, and closed-loop MAPE-K telemetry.
- 🛡️ **Systems security & low-level trust** — [**aegis-boot**](https://github.com/aegis-boot/aegis-boot): Signed boot. Any ISO. Your keys. A signed UEFI Secure Boot rescue environment that lets operators pick any ISO from a USB stick and `kexec` into it without leaving the chain of trust; eBPF container-escape probes; mutation-tested CI gates (*Plant the Defect, Watch the Gate*).
- 📜 **Civic technology & open law** — [**civic-source**](https://github.com/civic-source/us-code-tracker): The United States Code as Git-versioned Markdown. Tracking all 53,000+ sections across 54 Titles as immutable Git commits so anyone can run `git log`, `git blame`, and `git diff` on federal legislation.
- 🔌 **Homelab & bare-metal engineering** — Bare-metal BOSH + Cloud Foundry on a Dell PowerEdge R910 (256 GB RAM, 48 threads, Incus) alongside an always-on 3x Raspberry Pi cluster + Merlin AI VM automated with Ansible. Yes, on purpose. Yes, $150/month in power.
- 🎨 **Color science, typography & creative tooling** — [**svg-terminal**](https://github.com/williamzujkowski/svg-terminal) (declarative animated terminal SVGs for GitHub READMEs), [**oklch-terminal-themes**](https://github.com/williamzujkowski/oklch-terminal-themes) (742+ terminal color schemes in OKLCH with WCAG contrast metrics), and [**remarque**](https://github.com/williamzujkowski/remarque) (editorial typography design tokens).
